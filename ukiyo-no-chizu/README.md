# 浮世ノ地図（スマホ版）

**バージョン 1.2.1（2026-10-19）**

スマホのホーム画面に入れて、アプリのように遊べる版（PWA）です。iPhone・Android のどちらでも使えます。

## スマホに入れる

https で公開したページ（例: GitHub Pages）をスマホで開いて、

- **iPhone（Safari）**: 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
- **Android（Chrome）**: 右上の「︙」→「アプリをインストール」（または「ホーム画面に追加」）

アプリ内の「設定」→「スマホに入れる」からも案内が出ます（Android はそのままインストールできます）。

- 一度開いた地図・絵・国旗は端末に保存され、電波がなくても遊べる（`sw.js`）
- バージョンは `js/version.js` の `APP_VERSION`。更新して公開するときに上げると、端末のキャッシュも新しくなる
- アイコン: `icons/`、アプリ情報: `manifest.webmanifest`

## 作業と公開の流れ（このフォルダが唯一の元データ）

1. このフォルダで修正し、手元で確認する: `node tools/serve.js 8772` → http://localhost:8772
2. `js/version.js` の `APP_VERSION`（と `APP_BUILD`）を上げ、下の「更新履歴」に1行足す
3. 公開用フォルダへコピー: `node tools/publish.mjs`（`../../game/ukiyo-no-chizu` に入る。`proposals/` は入れない）
4. `game` フォルダで `ukiyo-no-chizu` だけを commit・push → https://fumifum1.github.io/game/ukiyo-no-chizu/

`proposals/` はタイトル・ホーム画面・UI のデザイン見本（開発用）。`tools/serve.js` で開いて `/proposals/index.html`・`/proposals/home.html` を見る。

## Android版（APK）

`apk/` に Android にそのまま入れられる APK を置いている（Capacitor でゲーム一式をアプリの中に入れたもの。URLバーなしの全画面、ネットなしでも起動）。

- 作り直し: `powershell -ExecutionPolicy Bypass -File tools\build-apk.ps1`（`-Install` を付けると USB でつないだスマホに入れる）
- ビルド用の作業場所は OneDrive の外の `C:\Users\user\AndroidBuild\ukiyo-no-chizu`、道具は `C:\Users\user\Android`（JDK 21・Android SDK）
- アプリの設定ファイルは `android-app/`。バージョンは `js/version.js` から自動で入る（1.1.0 → versionName 1.1.0 / versionCode 10100）
- アプリ版だけの動き: 「ありがとう」は端末の読み上げエンジンで話す、戻るボタンでダイアログ→画面の順に戻る
- 名画・国旗の画像とフォントはネットから読むので、電波がないときは創作浮世絵とふつうの明朝体になる

世界をはめると、名画になる。日本の47都道府県や世界の国々をピースにして地図にはめていくジグソーパズル。全部はまると一枚の名画が完成します。
クリアでもらえる小判をためて、世界の大陸パズル（国がピース、絵はその大陸の名画）や新しい絵柄と交換できます。

## 画面の流れ

1. **タイトル**: 持っている名画が画面いっぱいに出る（タイトルに戻るたびに変わる）。右上に縦書きの題箋「浮世ノ地図」。「はじめる」と今日のお題、下にメニュー（福引・図鑑・余興・画商・称号・設定）。その上に「クリエイターのサイト」（https://fumifum1.github.io/main/index.html）へのリンク。設定の中にも同じリンクがある
2. **地図えらび**: 地球儀を左右の矢印・スワイプ・下の点で回して地図を選ぶ。選んだ地図の国が朱色に光る（まだ開けていない地図は灰色で、小判で開けるボタンとついてくる名画が出る）。その下で地方・難易度・絵柄を選んで「はじめる」
3. **パズル**: 終わると地図えらびに戻る

背景は和柄（青海波）。夜モードでは藍地に金の青海波になる。

## 起動

```bash
node tools/serve.js
```

ブラウザで http://localhost:8770 を開く（依存パッケージなし）。

## 難易度

地図えらび画面の4つの切り替えで選ぶ。下に名前・ガイドの有無、もらえる小判、ベストタイムが出る。

| 難易度 | 都道府県名 | 形のガイド |
|---|---|---|
| 初級・手ほどき | あり | あり |
| 中級・名寄せ | あり | なし |
| 中級・形合わせ | なし | あり |
| 上級・達人 | なし | なし |

※ 日本の外枠（海岸線）と沖縄のはめ込み枠（左上）は、どの難易度でも表示します。
※ 形のガイドはゲーム中に「形」ボタン（PCは G キー）でいつでもオン・オフできます。ガイドなしの難易度でオンにすると、その回は自己ベストに記録されません。

## ミニゲーム

下のメニュー「余興」から遊べる1〜2分の遊び。結果に応じて小判がもらえる（1回最大30枚）。ベストは各ゲームのカードに出る。

| ゲーム | 遊び方 | 記録 |
|---|---|---|
| 国旗フラッシュ | 60秒で国旗の国を4択で当てる。まちがえると3秒へる | 正解数 |
| シルエット当て | 日本（都道府県）か世界（国）の黒い形を見て4択で当てる。10問 | 正解数 |
| 地球儀ダーツ | 地球儀をドラッグで回し、お題の国の場所をタップ。150km以内で100点、遠いほど減る。5投 | 合計点 |
| ありがとう聞き取り | 読み上げられた「ありがとう」が何語か4択で当てる。8問 | 正解数 |
| 名画スライド | 持っている名画の15パズル（3×3・4×4） | 手数（少ないほどよい） |
| 首都の札合わせ | 神経衰弱。日本は県と県庁所在地、世界は国（国旗つき）と首都。8組 | 手数（少ないほどよい） |

## 小判とお店

クリアすると小判がもらえ、メニューの「お店」（または鍵つきの地図・絵柄を押す）で交換する。値段や倍率は `js/app.js` の `PRICES`・`MULT`・`SEC_PER`。

- もらえる小判: 完成（ピース数 × 難易度の倍率。全体は最低10枚、地方ステージは最低5枚）、はじめてのクリア（同じ額をもう一度）、目標タイム内（+10／ステージ+5）、ヒント・ガイドなし（+10／ステージ+5）、今日のお題（+50）、称号（+20〜150）
- 倍率: 初級 0.5／中級 0.8／上級 1.2（ガイドなしの難易度で形ガイドを使った回は、ガイドありの難易度と同じ倍率）
- 地図: オセアニア 50 → 南アメリカ 80 → 北アメリカ 100 → ヨーロッパ 150 → アジア 200 → アフリカ 200（地図を開けると、その大陸の1枚目の絵もついてくる）
- 浮世絵: 神奈川沖浪裏（最初から）、凱風快晴 30 … 山下白雨 220、創作浮世絵 300
- 大陸の絵: 2枚目以降 60／90／120／150
- 以前の版（修行点）で遊んでいた記録は、最初に開いたときに小判（1点＝20枚）と持ち物に移す

## 地方ステージ

メニューの地図の下で「全体」か地方を選べる。地方ステージは7〜17枚の短いパズルで、その地方が画面いっぱいに拡大されて始まる。完成するとその絵全体があらわれる。

- 星: ★完成 ／ ★目標タイム内（1ピースあたり 初級6秒・中級8秒・上級10秒）／ ★ヒントもガイドも使わない
- 日本: 北海道・東北／関東／中部／近畿／中国・四国／九州・沖縄
- 世界: Natural Earth の地域区分をもとに分ける（例: アジア＝東アジア・東南アジア・南アジア・中央アジア・ロシア・西アジア）。オセアニアは7か国なので全体のみ
- 完成画面の「次は○○」で次の地方へ続けて遊べる

## 今日のお題

毎日1つ、持っている地図の地方ステージから「○分以内に」または「ヒントなしで」のお題が出る（その日の最初に決まり、途中で地図を買っても変わらない）。達成すると小判50枚と、連続日数の記録がつく。

## 称号

初陣・疾風・独力・達人・地方巡り・全国制覇・皆勤（お題7日連続）・蒐集家（絵柄10枚）・世界一周（6大陸）・小判長者（累計1000枚）の10種類。取ると小判がもらえる。メニューの「称号」で進み具合が見られる。

## 国旗ガチャと国旗図鑑

タイトルの下のメニュー「ガチャ」で小判を使って国旗を集める（1回30枚、10回280枚）。地球儀がくるくる回って止まり、止まった国のカード（国旗・国の形・豆知識・ありがとう）が出る。10回のときは一番レアな国に止まる。地球儀の金色の国は、もう国旗を持っている国。集めた国旗は「図鑑」に入り、押すと国旗・首都・言葉・豆知識・国の形と、その国の言葉の「ありがとう」が見られる。

- 対象: 地図に出てくる国のうち、日本が国家として承認している国と北朝鮮の190か国（台湾・パレスチナ・西サハラなどの地域は含めない）。一覧は `js/maps/countries.js`（ビルドで自動生成）
- レア度: 人口で決める（★★★＝100万人未満 7%、★★＝1500万人未満 28%、★＝それ以上 65%）。同じ国旗が出たら小判が戻る（★5・★★10・★★★30枚）
- 豆知識・首都・「ありがとう」: `js/country-facts.js`（手作業で作成。公開前に内容の確認をおすすめ）
- 「ありがとう」の音声: ブラウザの読み上げ機能（Web Speech API）を使う。端末にその言語の声がないときは、カタカナの読み方を日本語の声で読む
- 国旗の画像: [Flagpedia](https://flagpedia.net/)（flagcdn.com、パブリックドメイン）から読み込む
- 称号「万国旗」（国旗50か国）を追加

## 表示設定

メニューの歯車から: 夜モード、文字の大きさ（小・中・大）、置き場の位置（自動・下・右・左）、効果音、振動（対応スマホのみ）、ピースを指の上に出す、記録をすべて消す。設定は次回も引き継ぐ。

ゲーム中は周りの海に絵柄がうっすら表示され、完成すると鮮やかになる。「絵」ボタン（PCは E キー）で表示・非表示を切り替えられる。

## 絵柄

- 北斎・広重の浮世絵 9点（Wikimedia Commons のパブリックドメイン画像を読み込み）
- 創作浮世絵: `js/generator.js` が遊ぶたびに新しい絵を描く（富士・大波・川／朝・夕・夜／春夏秋冬・雨・雪をランダムに組み合わせる）
- 「おまかせ」は持っている絵柄から、前回と違うものをランダムに選ぶ
- ネットにつながらず浮世絵を読めないときは、自動で創作浮世絵に切り替える

絵柄を増やすには `js/arts.js` に追加する。

## 世界の大陸パズル

お店で地図を小判と交換すると、メニューの「地図」で大陸を選べるようになる。国がピースで、完成するとその大陸ゆかりの名画になる。

| 大陸 | ピース | 絵（1枚目は地図についてくる。2枚目以降はお店で交換） |
|---|---|---|
| アジア | 47か国 | 鄭敾「仁王霽色図」→ 范寛「谿山行旅図」→ スルターン・ムハンマド「ガユーマルスの宮廷」→ 金弘道「相撲」 |
| ヨーロッパ | 39か国 | ゴッホ「星月夜」→ モネ「印象・日の出」→ ブリューゲル「雪中の狩人」→ クリムト「接吻」→ フリードリヒ「雲海の上の旅人」 |
| アフリカ | 50か国 | ネフェルタリ王妃の墓の壁画 → エチオピアのイコン → ネバムンの狩猟 → ネバムンの庭園 |
| 北アメリカ | 17か国 | ビアスタット → ホーマー → トマス・コール → ベラスコ（メキシコ） |
| 南アメリカ | 14か国 | プエイレドン（アルゼンチン）→ ペドロ・アメリコ → アルメイダ・ジュニオル（ブラジル）→ ブラネス（ウルグアイ） |
| オセアニア | 7か国 | ストリートン → トム・ロバーツ → フォン・ゲラール → マッカビン |

- アフリカの近代の画家の作品は多くがまだ著作権の保護期間中のため、古代エジプトの壁画と17世紀頃のエチオピアのイコンを使っている
- バチカンやモナコなどピースにするには小さすぎる国・地域は、最初からはまった状態で表示する
- パズルに入らない周りの陸地（ヨーロッパの図のトルコや北アフリカなど）は薄く表示する
- 地図データは遊ぶときに読み込む（`js/maps/<大陸>.js`）。絵の一覧は `js/world-arts.js`

## 操作

- 右（スマホは下）の置き場からピースを地図へドラッグ。正しい位置の近くで離すと「ぴたり」とはまる
- 置き場に戻すと、ピースは置き場に戻る
- ホイール／ピンチで拡大、背景ドラッグで移動、□ボタンで全体表示
- ヒント: 光るピースと光る場所を示す（+20秒）
- 見本: 完成した絵を見る
- メニューの「絵柄」を押すと、絵柄の一覧が開く（スマホは下から出る）

## 地図データの再生成（地球儀用の js/maps/globe.js もここで作られる）

```bash
node tools/build-prefectures.mjs path/to/japan.geojson
```

```bash
node tools/build-world.mjs path/to/ne_50m_admin_0_countries.geojson
```

世界地図の元データ: [Natural Earth](https://www.naturalearthdata.com/) の `ne_50m_admin_0_countries.geojson`（[GitHub](https://github.com/nvkelso/natural-earth-vector/tree/master/geojson)）。大陸ごとの範囲・投影の中心は `tools/build-world.mjs` の `REGIONS` で設定。共通のジオメトリ処理は `tools/geo-utils.mjs`。

元データ: [dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson`。
伊豆・小笠原諸島（東京都）と奄美以南（鹿児島県）は、ピースが間延びしないよう省いています。
